# Skin Cancer Detection System

## Overview

This project is a Deep Learning based Skin Cancer Detection System developed using EfficientNet-B0 and the HAM10000 dataset.

The application predicts one of seven common skin lesion categories from dermoscopic images, generates Grad-CAM visualizations for explainability, and exports a professional PDF report containing prediction details.

---

## Features

- Deep Learning based skin lesion classification
- EfficientNet-B0 Transfer Learning
- HAM10000 Dataset
- Grad-CAM Explainability
- Confidence Score Estimation
- Professional PDF Report Generation
- Interactive Streamlit Dashboard
- Dark Theme User Interface
- Evaluation Metrics
- Confusion Matrix
- Classification Report

---

## Dataset

HAM10000 (Human Against Machine with 10000 Training Images)

Classes:

- Melanocytic Nevus
- Melanoma
- Basal Cell Carcinoma
- Benign Keratosis
- Actinic Keratosis
- Dermatofibroma
- Vascular Lesion
